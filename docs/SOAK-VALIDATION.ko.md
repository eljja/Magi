# GUI와 실제 모델 장시간 운전 검증 — 2026-09-20

## 현재 확인한 내용

- 배포 후보는 `oh-my-magi@0.1.1`, 실제 런타임은 OpenCode 1.18.31과 OmO 4.19.4입니다. [최소·최신 버전 및 3개 운영체제의 CI](https://github.com/eljja/Magi/actions/runs/35451257603)가 모두 통과했습니다.
- 최종 압축 패키지를 사용한 별도 GUI 시험 서버에서도 네이티브 설치, 3회 이상 연속 진행, 완료 표결 없는 연결, 세 인격의 주요 변화 보고와 원래 대화 전달, 중지·재개를 확인했습니다. 이 단계의 모델은 재현용 응답입니다.
- 이 PC에서는 별도 OpenCode 데스크톱 앱이 확인되지 않았습니다. 공식 OpenCode 웹 앱의 초기 화면은 열렸지만 후속 화면 검사는 자동 승인 검토에서 차단됐습니다. Magi 선택과 대화 보고의 실제 화면 검증은 아직 통과로 기록하지 않습니다.
- 로컬 감시 HTML의 기존 접근 차단은 우회하지 않았습니다. OpenCode 웹 앱은 내장 웹 자산 또는 `app.opencode.ai`를 제공하는 별도 앱이지만, 검토가 이를 이전 차단의 우회로 판단해 추가 허용을 요청한 상태입니다.
- npm 토큰은 게시 계정으로 인증됐습니다. 실제 게시 단계에서 npm의 추가 2단계 인증이 요구됐으며 브라우저 인증 대기 중입니다. 인증 성공이나 dry-run 출력을 게시 성공으로 취급하지 않습니다.
- OpenRouter의 계정 API와 현재 모델 목록을 확인했습니다. `nex-agi/nex-n2.5-mini:free`는 도구 호출을 지원하며 입력·출력 가격이 모두 0입니다. 사전 확인 당시 계정 사용액은 0, 무료 요청 잔여량은 880회였습니다. 다른 실행이나 날짜 변경에 따라 잔여량은 달라집니다.

## 장시간 시험 방식

`packages/oh-my-magi/script/live-smoke.ts`에 장시간 관찰 모드를 추가했습니다. 제품의 실행 횟수나 목표 유지 시간을 제한하는 설정이 아닙니다. 격리한 시험 프로젝트와 무료 모델만 사용하며, 실제 사용자 프로젝트의 모델 설정을 덮어쓰지 않습니다.

기본 관찰 시간은 **270분(4시간 30분)**입니다. 짧은 시험의 성공 조건인 3회 연속 회의와 실제 검사 통과에 도달해도 종료하지 않습니다. 다음 증거를 함께 확인해야 장시간 시험을 통과로 기록합니다.

1. 지정한 실제 경과 시간을 관찰하고, 살아 있는 런타임의 상태 갱신을 최소 4시간 확인합니다. 호스트가 멈췄거나 잠든 공백은 가동 시간으로 부풀리지 않습니다.
2. 세 인격의 논의·표결을 거쳐 실제 OmO `task → explore → read`가 실행되고, 진행 증거가 다음 회의로 이어져야 합니다.
3. 정기 또는 주요 변화 보고가 실제로 전달돼야 합니다. 보고 후에도 루프가 활성 상태이며, 더 뒤의 회의에서 새 진행 결과가 기록돼야 합니다.
4. 시험 프로젝트 밖에 별도로 보관한 원본 시험 파일로 최종 구현을 다시 검사합니다. 모델이 자체 테스트를 약화한 결과를 성공으로 인정하지 않습니다.

진행 중 `soak-observation.json`에 실제 경과 시간·관측 가동 시간·보고 시점·보고 이후 진전을 저장합니다. `progress.json`, `provider-calls.json`, `result.json`, 원래 회의록·보고 파일과 함께 판정 근거로 사용합니다. 인증 값은 결과 파일에 넣지 않습니다.

무료 요청 잔여량 소진, 공급자 오류, 런타임 중단, 사용자 중지 또는 시험 시간 종료를 구분합니다. 유료 모델로 자동 전환하지 않으며, 할당량 때문에 4시간에 못 미치면 장시간 성공으로 표시하지 않습니다. 보고 간격은 제품 기본값인 4시간을 유지하고 시험 시간을 조작해 보고를 발생시키지 않습니다.

## 실행 예

패키지 폴더에서 PowerShell로 실행합니다. API 키는 시작 후 숨김 입력으로 받고 명령줄·설정 파일에 직접 적지 않습니다.

```powershell
$env:MAGI_LIVE_SOAK='true'
$env:MAGI_LIVE_MINUTES='270'
$env:MAGI_LIVE_MODEL='nex-agi/nex-n2.5-mini:free'
$env:MAGI_OPENCODE_BIN='C:/실제/경로/opencode.exe'
bun run smoke:live
```

공개 npm 버전을 검증할 때에는 게시 확인 후 `MAGI_PLUGIN_SPECIFIER='oh-my-magi@0.1.1'`을 지정합니다. 기본값은 현재 로컬 패키지입니다. `MAGI_LIVE_PREFLIGHT='true'`는 인증·모델 가격·잔여량만 확인하고 모델 과제를 시작하지 않습니다. 실제 시험에서는 이 변수를 제거해야 합니다.

시험 산출물 폴더의 `STOP-TEST` 파일로 시험을 종료할 수 있습니다. 이는 사용자가 운영하는 다른 Magi 목표에 영향을 주지 않습니다. 시험 종료 시 시험용 목표와 자식 프로세스를 정리합니다.

**현재 장시간 운전 결과는 아직 없습니다. GUI 확인 후 시작할 준비 단계입니다.**
